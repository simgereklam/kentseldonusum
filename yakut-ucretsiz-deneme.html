Yakut — Tamamen ücretsiz ses denemesi

Bu deneme Gemini, ücretli ses API'si veya özel sunucu kullanmaz. Ses motoru, model ve JavaScript yalnızca kendi GitHub Pages sitemizden yüklenir. Ziyaretçinin ayrıca uygulama veya dosya indirmesi gerekmez.

Hazır. Başlamak için ses düğmesine basın.
Üretilen ses — Android oynatma kontrolü Ses otomatik duyulmadıysa yukarıdaki oynatıcının ▶ düğmesine dokunun. MP3 indirmek gerekmez; kayıt bu sayfada hazırlanır.
Site içi örnek cevaplar ücretsiz çalışır. Site dışı konularda Wikipedia'dan bilgi alınır.
Kaynağı aç Deneme sınırları: Site ilk açılırken yaklaşık 64 MB model verisini arka planda yükler. Ses üretimi cihazın hızına bağlıdır. Web araması yalnızca Wikipedia ile sınırlıdır; canlı hava, spor, bütün internet ve mikrofonla konuşma bu prototipte yoktur. Normal site ve 3D Yakut değiştirilmemiştir. Ses modeli: İlkiz Türkçe kadın Piper TTS (MIT). Tarayıcı WASM yaklaşımı: Piper browser demo. Ses dosyaları GitHub Pages içinde saklanır; ücretli API çağrısı yapılmaz.
