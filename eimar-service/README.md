# YAKUT e-İmar sunucu hazırlığı\n\nBu modül, Bağcılar resmî e-Devlet imar sorgu sayfasına Playwright ile **erişim keşfi** yapar. Gerçek ada/parsel sorgusu, harita analizi, CAPTCHA veya oturum otomasyonu **henüz yoktur**.\n\nKurulum: `pip install -r requirements.txt`, `playwright install chromium`, `uvicorn server:app --host 127.0.0.1 --port 8000`.\n\n`POST /inspect` gövdesi: `{\"district\":\"bagcilar\",\"ada\":123,\"parsel\":45}`. Yanıt `parcel_data_verified:false` döner.\n\nÜretimde kimlik doğrulama, oran sınırlama, erişim denetimi, kayıt tutma ve izin verilen belediye sorgu adaptörleri gerekir. Statik GitHub Pages bu Python servisini çalıştırmaz.\n
